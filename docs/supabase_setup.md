# Supabase 공유 저장소 설정 (관리자가 한 번)

> 실명·근태를 넣기 전에 회사 보안·개인정보 규정상 Supabase(외부 클라우드)를 써도 되는지 먼저 확인하십시오. 확인 전에는 가상 이름으로만 시험합니다.

## 1. 프로젝트 만들기 (약 5분)

1. https://supabase.com 에 가입하고 **New project** 를 누릅니다.
2. 이름(예: `team2g`), 데이터베이스 비밀번호(따로 보관), 지역 **Northeast Asia (Seoul)** 를 고르고 만듭니다.

## 2. 표와 함수 만들기

1. 왼쪽 메뉴 **SQL Editor** → **New query**.
2. 이 레포의 `docs/supabase_setup.sql` 내용을 모두 붙여 넣습니다.
3. 맨 아래 줄의 `'여기에-접근-코드'` 를 부서원과 나눌 **접근 코드**(12자 이상, 추측하기 어려운 문자열)로 바꿉니다. 이 값은 레포에 커밋하지 않습니다.
4. **Run** 을 누릅니다. "Success" 가 나오면 됩니다.

## 3. 웹앱에 연결 (배포 주소에서)

1. 왼쪽 메뉴 **Project Settings → API** 에서 **Project URL** 과 **anon public** 키를 복사합니다. (`service_role` 키는 절대 쓰지 마십시오.)
2. 배포된 웹앱의 **자료관리(관리자용)** 탭 → **공유 저장소 연결** 에 URL·anon public 키·접근 코드를 넣고 **연결** 을 누릅니다.
3. 이 기기에 이미 조직 설정이 있으면 "올리시겠습니까?" 에서 확인을 누릅니다. 없으면 **조직 설정** 에서 팀·이름·직책을 넣고 **조직 저장** 을 누릅니다.

## 4. 부서원에게 전달

1. 자료관리 탭 **직원용 링크 복사** → 메신저 등으로 **부서원에게만** 보냅니다.
2. 부서원은 휴대폰에서 링크를 한 번 열면 연결됩니다. 이후에는 홈 화면에 추가해 두고 **근태 입력** 에서 자기 이름을 골라 저장하면 됩니다.
3. 모든 화면 위쪽에 초록 점 "공유 저장소 연결됨" 이 보이면 정상입니다. 빨간 점이면 인터넷이나 접근 코드를 확인합니다.

## 5. 관리

- 쌓인 기록 보기: Supabase **Table Editor** → `attendance_log`(근태 이력), `org_snapshot`(조직 이력). CSV로 내려받을 수 있습니다.
- 접근 코드 바꾸기(링크가 새었을 때): SQL Editor 에서 `update app_config set v = '새-코드' where k = 'access_code';` 실행 → 새 직원용 링크를 다시 보냅니다. 예전 링크는 막힙니다.
- 무료 요금제는 1주일 동안 사용이 없으면 프로젝트가 일시 정지될 수 있습니다. 정지되면 Supabase 관리 화면에서 다시 켭니다.
